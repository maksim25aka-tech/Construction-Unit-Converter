#Репозиторий Construction Unit Converter
Описание
Construction Unit Converter – это набор консольных утилит на 8 языках программирования для быстрого и удобного перевода строительных единиц измерения. Программа поддерживает категории: длина, площадь, объём, масса, давление, температура, угол и скорость (в контексте строительной техники).

Проект создан как тестовый репозиторий для демонстрации реализации одной задачи на разных языках с использованием продвинутых возможностей: парсинг естественного ввода, автодетект категории, история конвертаций, цветной вывод, сохранение в файл.

Возможности
Интерактивный режим – запуск без аргументов открывает диалог с пошаговым вводом.

Однострочный режим – convert 10 m ft выводит результат мгновенно.

Поддержка категорий:

Длина: м, см, мм, км, дюйм (in), фут (ft), ярд (yd), миля (mi)

Площадь: м², см², ft², yd², акр, гектар

Объём: м³, см³, л, ft³, yd³, галлон (gal)

Масса: кг, г, мг, фунт (lb), унция (oz), тонна (t)

Давление: Па, кПа, МПа, бар, psi, атм

Температура: °C, °F, K

Угол: градус (°), радиан (rad), градиан (grad)

Скорость: м/с, км/ч, миль/ч (mph), узлы (kn)

Автоопределение категории по исходной и целевой единице – если обе единицы принадлежат одной категории, конвертация выполняется автоматически.

История конвертаций – сохраняется в памяти и может быть выведена командой history.

Сохранение результата в файл (опция --output).

Цветной вывод – подсветка чисел, единиц и сообщений.

Конфигурационный файл – запоминает последние использованные единицы и настройки вывода.

Обработка ошибок – дружественные сообщения при неправильном вводе.

Установка и запуск
Каждый файл является самостоятельной программой. Для запуска необходима соответствующая среда выполнения.

Язык	Установка	Запуск
Python	Python 3.8+	python converter.py [значение] [из] [в]
JavaScript	Node.js 14+	node converter.js [значение] [из] [в]
TypeScript	Node.js + npm install -g ts-node typescript	ts-node converter.ts [значение] [из] [в]
Go	Go 1.18+	go run converter.go [значение] [из] [в]
Java	JDK 11+	javac Converter.java && java Converter [значение] [из] [в]
C#	.NET SDK 6.0+	dotnet run или csc
PHP	PHP 8.0+	php converter.php [значение] [из] [в]
Ruby	Ruby 2.7+	ruby converter.rb [значение] [из] [в]
Использование
text
converter [значение] [из_единица] [в_единица] [опции]
Если аргументы не указаны, программа переходит в интерактивный режим.

Опции
Опция	Описание
-o, --output <file>	Сохранить результат (и историю) в файл.
--history	Показать историю конвертаций.
--clear-history	Очистить историю.
-h, --help	Показать справку.
Примеры
bash
# Однострочная конвертация
python converter.py 10 m ft
# Вывод: 10.00 м = 32.81 ft

# Конвертация с автоопределением категории
python converter.py 25.4 mm in
# Вывод: 25.40 мм = 1.00 in

# Интерактивный режим
python converter.py
# > Введите значение: 5
# > Из единицы: kg
# > В единицу: lb
# > 5.00 кг = 11.02 lb

# Сохранение результата в файл
python converter.py 100 km mi -o result.txt
Особенности реализаций
Python – использует argparse, dataclasses, enum, цветной вывод через ANSI, сохранение JSON.

JavaScript – использует commander, chalk, fs (синхронно), классы ES6.

TypeScript – строгая типизация, декораторы, аналогично JS.

Go – структуры, карты конверсий, горутины (для параллельного сохранения), flag.

Java – enum для категорий и единиц, java.util.function, java.nio.file.

C# – enum, Dictionary, Func, System.Text.Json для сохранения.

PHP – ассоциативные массивы, анонимные функции, readline для интерактива.

Ruby – метапрограммирование, блоки, OptionParser, цветной вывод.
